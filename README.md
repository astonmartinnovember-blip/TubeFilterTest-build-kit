# TubeFilterTest — Android сынақ жобасы

Мақсат: YouTube видеоларын жарнамасыз көру және экран сөнгенде аудионы ойнату.
Негізі: TeamNewPipe/NewPipe, v0.29.1, GPL-3.0-or-later.

**Бұл ZIP дайын APK емес. Бұл — APK жинауға арналған бастапқы жинақ.**
Android құрастыруы және нақты телефондағы жұмыс әлі тексерілген жоқ.
Бұл жинақ жаңа ойнатқыш жазбайды: NewPipe кодын жүктеп, сынақ қосымшасына
бөлек атау, белгіше және application ID береді. Ойнатқыш логикасы NewPipe-тан.
YouTube өзгерістерінен ойнату бұзылуы мүмкін; кейін жаңа upstream нұсқасын
тексеріп жаңарту керек болады.

## Телефонда бірден бастапқы мүмкіндіктерді тексеру

APK құрастыруын күтпей, түпнұсқа NewPipe-ты https://newpipe.net/ сайтынан
орнатып, видеода «Background / Фон» батырмасын сынауға болады. Бұл біздің
TubeFilterTest APK емес; тек негіздің сіздің телефонға жарамдылығын тексереді.

## GitHub-та біздің сынақ APK-ны жинау

1. GitHub-та `tubefiltertest` атты бос repository жасаңыз.
2. ZIP-ті ашып, оның ішіндегілерін repository түбіріне жүктеңіз.
   `.github/workflows/build-apk.yml` міндетті түрде сол жолда болуы керек.
   Браузер файл таңдағышы `.github` бумасын өткізіп жіберсе, GitHub-та
   Add file → Create new file арқылы осы толық жолмен файл жасаңыз да,
   жинақтағы workflow мәтінін көшіріңіз.
3. Actions → Build TubeFilterTest APK → Run workflow.
4. Құрастыру сәтті біткенде Artifacts → TubeFilterTest-debug-and-source.
5. Жүктелген ZIP ішіндегі `.apk` файлын телефонға жіберіп орнатыңыз.
   Бірнеше APK болса, алдымен атауында `normal` бар нұсқаны қолданыңыз.

Ноутбукта Android Studio қажет емес. APK GitHub runner-де жиналады.
GitHub тарифіндегі Actions лимиті қолданылады.

## Сынақ тәртібі

- Әр түрлі үш видеоны ашып, ойнату кезінде жарнама бар-жоғын қараңыз.
- Видео бетіндегі Background / Фон батырмасын басыңыз.
- Басқа қосымшаға ауысып, дыбыс жалғасатынын тексеріңіз.
- Экранды сөндіріп, кемінде бес минут тыңдаңыз.
- Хабарламадағы pause/play батырмаларын тексеріңіз.
- Дыбыс өшсе: телефон моделі, Android нұсқасы, қай әрекеттен кейін өшкенін жазыңыз.

## Осы алғашқы жинақтың шектері

- Бұл ресми YouTube қосымшасының ішіне араласпайды; жеке қосымша.
- Google аккаунтына кіру, ресми YouTube ұсыныстары мен синхрондау қарастырылмаған.
- Автордың видеосына өзі қосқан демеуші жарнамасын бұл жинақ арнайы өткізіп жібермейді.
- Debug APK сынауға арналған. GitHub runner әр құрастыруда жаңа debug кілтін
  жасайды, сондықтан келесі APK алдыңғысын тікелей жаңарта алмауы мүмкін.
  Тұрақты қолтаңбаны тарату алдында бөлек баптау керек.
- Ішкі NewPipe update checker осы fork үшін бапталмаған. TubeFilterTest-ті
  осы repository құрастырулары арқылы жаңартыңыз.
- Workflow әлі іске қосылмаған: нақты Gradle/APK нәтижесі GitHub Actions-та белгілі болады.
